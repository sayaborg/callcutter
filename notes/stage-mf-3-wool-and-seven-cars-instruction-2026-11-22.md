## 2. ウール(MF-3a)

### 2.1 形式

- 管(`exhaust.pipes[]`)に、任意の項目 `wool` を足す。単位は m。意味は「管の内側に巻いたグラスウールの厚み」。
- 一次管には書けない。書けるのは `pipes` だけ。
- 無い時と 0 の時は、今と同じ(損失は管壁の分だけ。出力は 1 サンプルも変わらない)。
- 受け付ける範囲:`0 < wool` かつ `2 × wool < diameter`。外れたら `exhaust/pipes/<n>/wool` で断る。
- `diameter` は今までどおり、管(消音器なら胴)の内径。ウールを巻いても `diameter` は書き換えない。
  継ぎ目の断面積も、遅れも、今までどおり `diameter` と `length` から決まる。ウールが変えるのは、損失だけ。
  (わけ:ウールはほとんどが空気で、遅い波は胴いっぱいに広がる。ウールが効くのは、波がウールを出入りする時の通りにくさだけ。
  `diameter − 2 × wool`(ガスがまっすぐ通る所の径)は、2.2 の損失の式にだけ出てくる。)
- 形式の版を上げるかどうかは、今の決まりに従う(任意の項目を足すだけで、今ある文書は読める)。

### 2.2 式

**考え。** ウールを巻いた管の壁は、たわむ壁。壁の手前にウールの通りにくさ(抵抗)があり、その奥にウールの厚み分のガス(ばね)がある。
抵抗とばねが直列なので、遅い波は壁に入れず(ばねが硬い)何も取られない。速い波は抵抗の分だけ取られる。
つまりウールは高音を選んで吸っているのではなく、結果としてそうなる。

**量。** 新しい定数は 1 つだけ。

| 量 | 値 | 出どころ |
| --- | --- | --- |
| `resistivity`(ウールの通りにくさ σ) | 30,000 Pa·s/m² | **見積もり**。建材用の軽いグラスウールの実測は 3,000〜6,000(Tarnow 2002)。消音器の詰め物はそれより密で、排気は熱い分だけ粘るので、桁として無理のない値を置いた。測定の裏づけは無い |
| `pressure`(まわりの圧力 p0) | 101,325 Pa | 大気圧。もう同じ値の定数があれば、それを使う |
| γ、c | 1.4、480 m/s | 今ある定数(`GAS.gamma`、`ACOUSTICS.waveSpeed`) |

**式。** 管 1 本(長さ `length`、径 `diameter`、ウール `wool`)について。

```
R  = resistivity × wool                                   壁の抵抗(Pa·s/m)
ρc = γ × pressure / c                                     ガスの抵抗(約 295.5)
f0 = γ × pressure / (2π × R × wool)                       効き始める高さ(Hz)。抵抗とばねがつり合う所
A  = (2 × length / (diameter − 2 × wool)) × (ρc / R)      1 回通る間の損失の上限(ネーパー)
損失(f) = A × f² / (f0² + f²)                             1 回通る間の損失(ネーパー)
```

- `2 × length / (diameter − 2 × wool)` は、ガスが通る所の(周長 ÷ 断面積)× 長さ ÷ 2。壁に沿って走る波が、壁に吸われる割合の形。
- 厚みを 2 倍にすると、`f0` は 1/4 に、`A` は(通る所が狭くなる分を除けば)半分になる。厚いほど低い所から、浅く取る。

**フィルター。** ウールを書いた管の線 1 本につき、1 次の棚を 1 つ足す。管壁の損失(4 段の棚)には触らない。

```
fp = f0 × sqrt((1 − exp(−2A)) / (2A))                     極。ずっと低い所の損失が、上の式(A f²/f0²)と同じになる置き方
fz = min(fp × exp(A), 0.49 × rate)                        零点。ずっと高い所の損失が A になる置き方。率の上限は管壁の棚と同じ 0.49
fp ≥ 0.49 × rate の時は、その率では棚を置かない(管壁の棚で、率が運べない角を外すのと同じ扱い)
```

係数は、管壁の棚と同じ作り方(双一次変換、角を合わせる)。

監査役の写し(道具のカーネル)では、こう書いてある。K が聴いた音は、これで鳴らした物。

```ts
export const WOOL = { resistivity: 3e4, pressure: 101325 };
/** [b0, b1, a1] of y[n] = b0 x[n] + b1 x[n-1] - a1 y[n-1], or null where the rate does not carry the pole. */
export function woolShelf(length: number, diameter: number, wool: number, rate: number): [number, number, number] | null {
  const R = WOOL.resistivity * wool, stiff = GAS.gamma * WOOL.pressure;
  const f0 = stiff / (2 * Math.PI * R * wool);
  const A = ((2 * length) / (diameter - 2 * wool)) * (stiff / ACOUSTICS.waveSpeed / R);
  const fp = f0 * Math.sqrt((1 - Math.exp(-2 * A)) / (2 * A));
  if (fp >= 0.49 * rate) return null;
  const fz = Math.min(fp * Math.exp(A), 0.49 * rate);
  const K = 2 * rate, wp = K * Math.tan((Math.PI * fp) / rate), wz = K * Math.tan((Math.PI * fz) / rate), g = wp / wz, a0 = K + wp;
  return [(g * (K + wz)) / a0, (g * (wz - K)) / a0, (wp - K) / a0];
}
```

掛ける所は、管壁の損失のすぐ後(管に入る所。`write` の中で、4 段の棚の出力 `y` を作った直後)。

```ts
// 線 l にウールの棚がある時だけ。woolState は線ごとに 2 つ(前の入力、前の出力)。
const shelved = b0 * y + b1 * woolState[2 * l] - a1 * woolState[2 * l + 1];
woolState[2 * l] = y;
woolState[2 * l + 1] = shelved;
y = shelved;
```

- `woolShelf` と定数は `exhaust-acoustics.ts` に、出どころの注記(上の表の中身)を付けて置く。`exhaust-waveguide.ts` が管の `wool` を見て棚を持つ。
- 管の往きと還りの両方の線に、同じ棚を置く。一次管の線には置かない。
- 率が変わる時(ENGINE SOUND QUALITY)は、管壁の棚と同じ所で作り直す。

### 2.4 分かっている粗さ(直さない。報告に書くだけ)

- 通りにくさ 30,000 は見積もり(2.2 の表)。
- 損失は、波の高さによらない。ウールの中の容積、流れの抵抗(波が高い時だけ効く分)は表していない。
  どちらも試して、K の耳で外れた(流れの抵抗、ウールを管の横の空間として書く形)。
- 零点が率の上限(0.49 × 率)に当たる管では、一番上の高さの損失が率で少し違う。
- NSR500 の消音器は、20 mm 巻くと通る所が 22 mm になる(スティンガーと同じ太さ = ストレート構造)。実車もこの形。

## 3. 排気の書き方の決まり(MF-3b。`docs/calibration.md` の「Exhaust topologies」と `docs/audio.md`)

今の決まり(MF-1 の「消音器は太い管」、MF-2 の「タービンは喉と小部屋」)を、次の形に書き直す。

**実車に寄せる物**

1. 弁の `diameter` と `open`、集合の仕方(どの気筒がどこで合わさるか、左右がどこで合わさるか)は、実車どおり(今までどおり)。
2. **各管の長さは、実車に忠実にする。** 一次管も、集合の後ろの管も、テールも。資料が無ければ部品図や写真から見積もる。
   長さは 0.02 m の倍数で書く。
3. **管の太さは、実車の内径 × 1.14。** 一次管も含める。
   掛けない物:タービンの喉と小部屋(5.)、膨張室の胴(4.)、2 ストロークの全部(7.)。
   K の言葉:「大体、ひとまわり太くしてる時点で近似」。途中で少しずつ太さが変わる所は、細かく追わなくてよい。

**耳で決める物**

4. **膨張室(消音器や触媒の胴。太い管で書く)の大きさと位置は、K が耳で決める。** 実車と違ってよい。その時の決まり:
   - 直列に並ぶ膨張室の間の管は、**0.08 m** で揃える。
   - 原則として、**エンジン側の膨張室にウール(`wool` 0.02)を書き、そちらの容積を大きくする。**
   - ウールを書くのは、1 本の道につき 1 か所。厚みは全車 0.02。
   - **ターボ車は、前の膨張室の代わりにタービンがあるので、膨張室は 1 個でもよい。** その時は、その 1 個にウールを書く。
   - 「一回り大きく/小さく」は、径を × 1.14/÷ 1.14(容積で約 1.3 倍)。

**タービン**

5. タービンは、管 2 本で書く。ターボ 1 個につき 1 組。
   - **喉**:長さ 0.08 m(全車共通)。径は、実物のタービンの喉の断面積と同じ面積の円の径(ツインスクロールは 2 つの面積の和)。
   - **小部屋**:長さ **0.12 m** × 径 150 mm(全車共通。今の 0.11 m を 2 cm 刻みに合わせた)。
   - 喉と小部屋は、太くしない。ウールを書かない。ウェイストゲートと、左右をつなぐ渡りの管は、書かない。
   - 小部屋の容積は、膨張室の容積に数えない。

**そのほか**

6. 同じ形の枝は 1 本にまとめて、径を √2 倍(今までどおり)。
   片側だけ長さが違う枝は、まとめない(左右の差は、実車どおりに残す)。
7. **2 ストロークは、現車どおりに書く。** チャンバーは膨張室(4.)ではない。太くしない、寄せない、大きさを変えない。
   チャンバーの後ろのサイレンサーには `wool` 0.02 を書く。
8. **整数比。** 実車の長さを優先する。その上で、膨張室の長さと位置(= 耳で決める所)は、同じ道に並ぶ管の長さと簡単な整数比にしない。
   - 監査役の検査:2 本の長さ `A`、`B`(cm)の比を既約分数 `p/q = A/B` にし、`max(p, q) ≤ 4` かつ `p × 24000 / A ≤ 3200` なら当たり。
   - 当たったら、膨張室の長さか位置を 0.02 m ずらす。**実車の長さどうし、共通のタービン(0.08、0.12 m)、膨張室の間の 0.08 m が当たる分は、そのまま残す。**
9. 車ごとの例外を作らない。コンプは 2:1 のまま。

- 2 cm 刻みと整数比の検査を、道具(定義を読む検査)に入れるかどうかは、実装者が K に聞く。入れない時は、文書の決まりとして書く。
- `docs/calibration.md` の「Exhaust topologies」の文と表を、この決まりと 4. の値に直す。
  今の文の「the lengths near the real car's … and the diameters chosen by ear」と「a room 0.11 m long」は、もう合わない。
- 出どころの欄と `metadata.note` には、4. の車ごとの出どころを書く。**部品図・写真からの見積もりは、見積もりと書く**(測った値のように書かない)。
  「膨張室の大きさと位置、管の太さの 1.14 倍、ウール 20 mm は、K が耳で決めた(2026-11-22)」と書く。

## 9. しない事、止まる所

- DELTA HF INTEGRALE と、4. の 7 台のほかの車の定義に触らない。
- 弁の値を車ごとにいじらない。全車に同じ係数を掛ける案は試して、K が取り下げた。
- コンプの比(2:1)、点火の乱数(3 %)、波の切り立ち(1.2)、聴く量(出口の圧力)を変えない。どれも試して、K が今のままと決めた。
- カーネルの式を、2.2 のほかに変えない。管壁の損失(`wallLossSections`、`wallLossWeights`)には触らない。
- ウールの厚みを車ごとに変えない。通りにくさの値を変えない。4. の長さと径を、整数比を避けるためでも動かさない(動かしたい時は K に聞く)。
- 止まる所:`wool` を書かない定義の出力が変わった時。管壁の損失の検査の結果が変わった時。2.3 の表の係数が合わない時。
  7 台のほかの音量や音の値が変わった時。管の本数や継ぎ目の形を、今の形式と解き手が受け付けない時。5. の止まる所。
