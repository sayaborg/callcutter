# 実装者への指示:カーネルの始まりの大きな音を直す(ES-2)

2026-11-21。エンジン音のスレッドから。ES-1 の報告の「作り直した直後の大きな音」への直しです。
始める所は、その時の main です(ES-1c の `e08bdb2` より後)。

## 1. 原因

カーネルが始まった時、弁がもう開いている筒が、仮の中身(初めに入れてある `gas` と `density`)を一気に吐いています。
正本(ES-1 の付録 A)で測ると、アイドルの始まりの 0.3 秒の頂点は、落ち着いた後より中央で 41 dB、最大で 51 dB 大きいです(`87dcbbdd` の音の定義 35、48 kHz)。

## 2. 直し

決まりを 1 つ足します:**筒は、カーネルが始まってから最初に弁が開くまで、何も吐かない。** 最初に弁が開く時に、いつもどおり中身が決まります。

正本で言うと、次の 3 か所です(書き直したカーネルの、同じ所を直してください)。

1. 筒ごとに「弁が一度でも開いたか」を持つ(初めは、開いていない)。
2. 弁が開く瞬間(正本の `if (crossed) {` の中の最初)で、それを「開いた」にする。
3. 弁の流れを解く条件(正本の `if (since < valve.open) {`)を、「開いている間で、かつ、一度でも開いた筒」にする。

- 筒の初めの仮の値(正本の `gas` を行程容積で、`density` を `pipeKelvin / burnedKelvin` で埋めている所)は、使われなくなります。埋めるのをやめてください。
- ほかは変えません。コンプの大きさが 0 から始まる事も、今回は変えません。音を丸める仕組みや、無音で待つ時間を足さないでください。

## 3. 確かめ

- Claude が、直した正本で測った値(同じ 35 の音の定義、48 kHz、アイドル、始まりの 0.3 秒の頂点 ÷ 落ち着いた後の頂点):
  カーネルだけで −3.9〜+4.0 dB(中央 −0.6)。コンプを通した後で −1.7〜+6.8 dB(中央 +4.1)。
- 4 つの速さとも、全部の音の定義で壊れません(音量の手順の走らせ方、レッドラインの 1.04 倍での燃料カット、全閉でのアフターファイヤ)。
- **始まった後の音も、数字としては変わります**(筒が最初に吐く物が変わると、その後の波の重なり方が変わるため。音の性質は同じです)。
  そのため、正本と比べるテストの保存した値(`tests/audio/exhaust-render.values.json`)は、**直した正本で作り直してください**。
  直した正本は、ES-1 の付録 A に上の 3 か所の直しを入れた物です。書き直したカーネルと、差が丸めだけ(1e-9 以下)である事を確かめてください。
- 音量を揃える数は、測り直してください(手順の走らせ方の最初の 1 秒が変わるため)。手順の版を上げるかは、リポジトリの決まりで決めてください。

## 4. 入れ方と報告

- Node 24 の `npm test` と PR の CI の `build` が通ったら、main に入れてよいです。テストは 1 つずつ流してください。
- 報告は、最初の一行に「どこで聴けるか」を書き、平易な日本語で、次を書いてください。
  - ES-1 の報告と同じ測り方での、作り直した直後の音の大きさ(アイドル、PX200E、中くらいの回転で全開)。直す前の値と並べて。
  - 音量を揃える数が、車両ごとにどれだけ動いたか(一番大きく動いた物)。
- この指示と今の作りが合わない時は、仮の形を積まずに、止めて聞いてください。
